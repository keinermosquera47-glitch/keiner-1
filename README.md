# Arepas LUCHI

Página web de pedidos de arepas, pensada para móvil. El cliente arma su arepa (tipo, tamaño, relleno, toppings y salsas), ve el precio en tiempo real, la agrega al carrito y envía el pedido por WhatsApp.

## Cómo cambiar precios y menú
Abre `index.html` y busca estas líneas dentro de `<script>`:
- `WA` → número de WhatsApp
- `TYPES`, `SIZES`, `FILLS`, `TOPS`, `SAUCES` → ingredientes y precios
- `CLASSIC` → menú clásico

## Publicar con GitHub Pages
Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
